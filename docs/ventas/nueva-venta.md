# Registrar una nueva venta

Las ventas se hacen desde **Nueva venta** en el menú lateral.

### Pasos

1. Tocá "Nueva venta".
1. Elegí el cliente. Si no querés registrar a la persona, usá un cliente "Consumidor Final".
1. Agregá los productos buscándolos por nombre o código.
1. Confirmá la entrega y guardá.
!!! note "💡 Nota"
    Se puede buscar por código nuevo y por código alternativo (respetando mayúsculas). Los campos con asterisco rojo son obligatorios.
