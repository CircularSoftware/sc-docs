# Editar tu web: banners, textos y botón de WhatsApp

El contenido de tu tienda se edita desde el menú **Mi sitio web**, en sus tres secciones: **Diseño**, **Páginas** y **Configuraciones**.

### Qué podés editar

- Página principal (banners y secciones de imagen + texto): en **Mi sitio web → Diseño**.
- Pie de página, botón de WhatsApp y datos de contacto: en **Mi sitio web → Configuraciones**, pestañas **Pie de página** y **Contacto y redes**.
- Páginas institucionales (preguntas frecuentes, términos y condiciones): en **Mi sitio web → Páginas**.
!!! tip "Tip"
    Usá los banners con las medidas indicadas para que se vean bien. Si necesitás una medida, escribinos.
