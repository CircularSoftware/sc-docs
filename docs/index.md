# Centro de ayuda

Bienvenido. Usa el buscador de arriba para encontrar respuestas, o navega por las
secciones en el menú lateral.

!!! tip "¿No encuentras lo que buscas?"
    Escribe con tus propias palabras en el buscador. Si no aparece nada exacto, te
    mostraremos artículos parecidos bajo *«Quizás te sirva:»*.

Esta página se genera automáticamente desde Notion. Para editar el contenido, abre la
base de datos **Docs** en Notion y cambia el estado del artículo a **Published**.
